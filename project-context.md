# Contesto del progetto

Questo file è per te (l'utente), non per Claude. Scrivi qui, in linguaggio naturale, tutto ciò
che già sai sul progetto prima ancora di iniziare il setup: obiettivi, vincoli, decisioni già
prese, cose da evitare. Claude leggerà questo file insieme a `setup.md` alla primissima
interazione con la repo, così non dovrai ripetere a voce le stesse informazioni.

Le sezioni sotto sono solo un suggerimento: cancellale, rinominale, riordinale o sostituiscile
liberamente. Ogni progetto ha un contesto diverso — non serve rispettare questa struttura.
